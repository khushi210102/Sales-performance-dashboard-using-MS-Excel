Sales Performance Dashboard (Excel Project)

A macro-enabled Excel dashboard designed to analyze sales performance across regions and track individual sales executive contributions. This project demonstrates data cleaning, KPI automation, visualization, and interactive dashboard building using Microsoft Excel.

 Project Overview:
This Excel project provides a complete sales analytics solution using two structured sheets:

Dashboard – A clean, interactive interface summarizing:
Total Sales

Target Achieved %

Away From Target %

Sales Executive Comparison

Region-wise insights

Raw_Data – Contains detailed daily sales information for each sales executive, including:
Employee Code

Region

Day-wise sales

Targets

Automatically calculated KPIs
